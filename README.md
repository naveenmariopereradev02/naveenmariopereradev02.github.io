# Naveen Perera — Personal Developer Portfolio ⚡

Modern, auto-updating developer portfolio hosted on **GitHub Pages**, built for **Naveen Perera** (BSc (Hons) Computer Science Undergraduate at University of Westminster / IIT Sri Lanka).

## ✨ Key Features

1. **Auto-Updating Projects (`projects.json`)**: A scheduled GitHub Actions workflow (`update.yml`) fetches public repositories, extracts README summaries, and merges manual customizations from `overrides.json`.
2. **Interactive Project Timeline**: Displays project start and latest activity dates. Active repositories remain marked as **Ongoing** and continue progressing on the timeline.
3. **Auto-Detected Repository Languages**: Calculates language percentages and repository counts from GitHub Linguist byte stats so any new language you code in appears automatically in the **GitHub Bento Grid** and **Skills** section.
4. **Manual Customization (`profile.json` & `overrides.json`)**: Easily edit your bio, CV highlights, certifications, FAQ queries, social links, or per-project overrides without touching HTML/JS code.
5. **Dark & Light Mode**: Smooth theme switcher in the top-right corner with persistent preference.

## 📁 Project Structure

```text
.
├── index.html                  # Portfolio UI (Hero, About, GitHub Bento Grid, Skills, Projects, Timeline, Certifications, Queries, Contact)
├── profile.json                # Personal details, CV data, skills, certifications, FAQ queries, and social links
├── overrides.json              # Per-repo overrides (custom title, role, highlights, featured, ongoing, hide)
├── projects.json               # Auto-generated by GitHub Actions (seeded with CV projects for local preview)
├── scripts/
│   └── fetch-projects.js       # Node.js script executed by GitHub Actions to update projects.json
└── .github/
    └── workflows/
        └── update.yml          # Daily + on-push GitHub Actions workflow
```
