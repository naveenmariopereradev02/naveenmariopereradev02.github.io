# Naveen Perera — Personal Developer Portfolio ⚡

Modern, auto-updating developer portfolio hosted on **GitHub Pages**, built for **Naveen Perera** (BSc (Hons) Computer Science Undergraduate at University of Westminster / IIT Sri Lanka).

## ✨ Key 2026 Portfolio Features

1. **Auto-Updating Projects (`projects.json`)**: A scheduled GitHub Actions workflow (`update.yml`) fetches public repositories, extracts README summaries, and merges manual customizations from `overrides.json`.
2. **Live GitHub Commit Ticker & Bento Grid**: Displays live push events, repository streaks, interactive contribution heatmap, and auto-detected language distributions.
3. **Interactive Project Timeline (Ongoing vs Completed)**: Displays project start and latest activity dates. Active repositories remain marked as **Ongoing** and continue progressing on the timeline.
4. **Command Palette (`⌘K` / `Ctrl + K`)**: Raycast/Linear-style quick launcher to search projects, jump to sections, toggle themes, preview/download the CV, or copy contact details.
5. **Interactive System Architecture & Case-Study Modal**: Visualizes end-to-end architecture pipelines and engineering decisions for each project (including private NDA repositories like **TrustLink OAuth 2.0 / OIDC SSO**).
6. **Ask Naveen's AI & Developer CLI (`AI · CLI`)**: Interactive terminal and AI assistant powered by `profile.json` and `projects.json` (`whoami`, `projects`, `skills`, `certs`, `cv`, `contact`).
7. **One-Click CV Preview & Download (`cv/`)**: Embedded Liquid Glass PDF viewer and direct download modal linked to `./cv/Naveen_Perera_CV.pdf`.
8. **Circular Reveal Theme Transition & Spotlight Border Glow**: Bidirectional circular `clip-path` View Transition between Dark and Light modes plus cursor-tracking radial spotlight cards.

## 📁 Project Structure

```text
.
├── index.html                  # Portfolio UI & 2026 Interactive Features
├── profile.json                # Personal details, CV data, skills, certifications, FAQ queries, and social links
├── overrides.json              # Per-repo overrides (custom title, role, highlights, featured, ongoing, private NDA)
├── projects.json               # Auto-generated by GitHub Actions (seeded with CV projects for local preview)
├── cv/                         # Curriculum Vitae PDF folder (Preview & One-Click Download)
├── scripts/
│   └── fetch-projects.js       # Node.js script executed by GitHub Actions to update projects.json
└── .github/
    └── workflows/
        └── update.yml          # Daily + on-push GitHub Actions workflow
```
